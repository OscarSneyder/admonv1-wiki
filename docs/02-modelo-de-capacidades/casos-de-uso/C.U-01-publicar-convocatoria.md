# C.U-01 · Publicar convocatoria

> **Alcance:** incluido en la RBS (tajada TJ-02). Mientras tanto, las convocatorias se cargan como datos semilla para avanzar con la tajada inicial sin depender de este C.U. La convocatoria define el número de cupos ([RN-14](../../01-modelo-de-negocio/04-reglas-de-negocio.md#reglas-identificadas-por-implementar)) y el periodo de vigencia de la asignación ([RN-15](../../01-modelo-de-negocio/04-reglas-de-negocio.md#reglas-identificadas-por-implementar)), porque ambos varían según el conjunto.
